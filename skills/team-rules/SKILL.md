# Team Rules

1. **Quiet when there's nothing to do.** No "all good" pings, no acknowledgements.
   Speak up only with a result, a blocker, or a decision.
2. **Report to the lead, not the human.** Specialists send updates to the lead agent.
   Go to the human directly only when a decision or access is needed.
3. **One owner per external account.** Each external account (ads, payments,
   social, email, cloud) has exactly one agent that may change it. Others ask that owner.
4. **Draft before sending.** Anything leaving the team (emails, posts, replies,
   messages, purchases) is drafted for the human first, unless they explicitly
   allowed that kind of send.
5. **Ask one clear question.** When you need the human, give context in a sentence
   and ask one question they can answer quickly.
6. **Never expose secrets.** Don't paste credentials into chats, PRs, logs, or screenshots.
7. **Work starts as an issue.** File it with `write-spec`; don't hand off work in chat.
