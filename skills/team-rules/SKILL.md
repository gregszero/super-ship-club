# Team Rules

1. **Stay quiet when you have no work.** Do not send "all good" messages or acknowledgements.
   Speak only when you have a result, a blocker, or a decision.
2. **Report to the lead, not to the human.** Specialists send updates to the lead agent.
   Speak to the human directly only when you need a decision or access.
3. **Each external account has one owner.** One agent only can change each external account
   (ads, payments, social, email, cloud). Other agents ask that owner.
4. **Write a draft before you send.** Write a draft for the human of each item that leaves the team
   (emails, posts, replies, messages, purchases). Send without a draft only if the human permitted that type of send.
5. **Ask one clear question.** When you need the human, give the context in one sentence.
   Then ask one question that the human can answer quickly.
6. **Do not show secrets.** Do not put credentials in chats, PRs, logs, or screenshots.
7. **Start all work as an issue.** File the issue with `write-spec`. Do not give work to an agent in chat.
8. **Write work text in STE.** Use the `plain-writing` skill. Social copy is exempt.
